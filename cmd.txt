# 一、机器人、输入与启动
#
# --ip IP
#   遥操、数据采集和测试脚本的机器人 IP；默认 172.16.0.2。

#   启用后按 PS 键依次采集 Pre、Post 当前姿态，Grasp/Release 阶段自动使用零容差。

#
# --home-first
#   joint_keyboard_control 启动时先执行 Home 复位；默认不执行。
#
# --dry-run
#   joint_keyboard_control 仅打印关节目标，不连接或控制机器人。
#
# --reset-duration SEC
#   Home 复位时长；默认 5.0 s。
#
# --control-hz HZ
#   Coordinator 的策略与规划频率；默认 10 Hz。
#
# --use-gripper / --no-use-gripper
#   Coordinator 是否连接夹爪；默认启用。
#
# --no-cameras
#   不启动 RealSense 相机。
#
# --cam1-serial SERIAL / --cam2-serial SERIAL
#   Coordinator 的两台 RealSense 序列号；默认 346222072769 / 938422075745。
#
# --no-robot
#   不连接真机，仅运行 Python 逻辑。


# 二、运动规划与参考轨迹
#
# --planner-mode {direct,baseline_sqp,shadow_sqp}
#   默认 direct。
#   direct       ：7D 笛卡尔动作直接进入笛卡尔参考轨迹和阻抗控制。
#   baseline_sqp ：7D 笛卡尔动作先经 SQP 求解为绝对关节目标。
#   shadow_sqp   ：Shadow 目标姿态 + Baseline SQP，再生成绝对关节目标。
#
# --tracker-mode {auto,pid}
#   默认 auto：笛卡尔 Reference 选择内部 cartesian_impedance，关节 Reference 选择内部 joint_pid。
#   pid：同样按 Reference 空间选择实现；不会把笛卡尔 Reference 转成关节 Reference。
#   joint_pid 先做有界泄漏 PID 关节参考修正，再由关节阻抗转换为扭矩。
#
# --reference {min_jerk,linear,cubic,motion_limited}
#   Reference profile 与 Planner 独立选择，再由 Router 检查空间兼容性。
#   所有启动命令统一使用 --reference。
#   key_control/data_recorder 默认 linear；coordinator 默认 min_jerk。
#   笛卡尔空间可选 min_jerk/linear/cubic/motion_limited。
#   关节空间可选 min_jerk/linear/cubic；joint motion_limited 尚未实现。
#   min_jerk      ：五次最小加加速度插值，段首尾速度和加速度为零。
#   linear        ：线性插值，响应直接。
#   cubic         ：三次平滑插值，段首尾速度为零。
#   motion_limited：按速度和加速度上限在线跟踪，适合连续遥操。
#
# 关节 linear/cubic/min_jerk 固定在一个低频控制周期（1 / control_hz）内走完。
#
# 路由关系：Planner 决定输出空间；Reference 决定目标随时间的变化；Tracker 决定误差到扭矩的映射。
#           三者分别选择，但必须属于同一空间；Router 只负责校验和连接。


# 三、笛卡尔动作限制
#
# --max-translation-velocity M_S
#   末端平移速度上限；默认 0.2 m/s。
#
# --max-rotation-velocity RAD_S
#   末端旋转速度上限；默认 pi/4 rad/s。
#
# --max-translation-goal-error M
#   命令位置与实测位置的最大允许距离；默认 0.3 m。
#
# --max-rotation-goal-error RAD
#   命令姿态与实测姿态的最大允许误差；默认 pi/6 rad。
#
# --motion-limited-max-translation-velocity M_S
# --motion-limited-max-rotation-velocity RAD_S
#   motion_limited 参考的速度上限；默认是对应基础速度的 1.2 倍。
#
# --motion-limited-max-translation-acceleration M_S2
# --motion-limited-max-rotation-acceleration RAD_S2
#   motion_limited 参考的加速度上限；默认是对应 motion_limited 速度的 5 倍。
#
# --policy-translation-scale-m M
# --policy-rotation-scale-rad RAD
#   Coordinator 将 Policy 原始动作换算为物理增量的缩放系数；均默认 0.01。
#
# --max-translation-step M / --max-rotation-step RAD
#   固定轨迹脚本每个 10Hz 动作的平移/旋转尺度；默认 0.1 m / pi/4 rad。
#
# --scale FLOAT
#   固定轨迹的整体动作缩放；默认 1.0。
#
# --settle SEC
#   最后一个动作后的稳定等待时间；固定轨迹默认 4.0 s。


# 四、Shadow SQP 目标姿态与容差

# --shadow-stage NAME
#   Shadow 语义阶段键；阶段或 prompt 改变时重置 Shadow anchor。
#   key_control/data_recorder 默认 teleop；Coordinator 默认 default。


# 五、SQP 求解器（Coordinator 可配置，Baseline/Shadow 共用）
#
# --sqp-max-iterations INT                 最大 SQP 迭代数；默认 20。
# --sqp-max-time-s SEC                     单拍求解时间上限；默认 0.095 s。
# --sqp-derivative-epsilon FLOAT           数值导数步长；默认 1e-7。
# --sqp-step-tolerance FLOAT               步长收敛阈值；默认 1e-7。
# --sqp-position-tolerance M               位置约束容差；默认 1e-5。
# --sqp-rotation-tolerance RAD             姿态约束容差；默认 1e-4。
# --sqp-inequality-tolerance FLOAT         不等式可行容差；默认 1e-7。
# --sqp-trust-region RAD                   关节搜索信赖域；默认 0.35。
# --sqp-merit-penalty FLOAT                约束违反惩罚；默认 1000。
# --sqp-line-search-iterations INT         最大线搜索次数；默认 12。
# --sqp-qp-iterations INT                  每次 SQP 的最大 QP 迭代数；默认 32。
#
# --sqp-velocity-weight FLOAT              关节速度目标权重；默认 0.7。
# --sqp-acceleration-weight FLOAT          关节加速度目标权重；默认 0.5。
# --sqp-jerk-weight FLOAT                  关节加加速度目标权重；默认 0.3。
# --sqp-joint-limit-weight FLOAT           关节限位避让权重；默认 0.1。
# --sqp-manipulability-weight FLOAT        可操作度权重；默认 1.0。
# --sqp-self-collision-weight FLOAT        自碰撞避让权重；默认 0.01。
# --sqp-tolerance-weight FLOAT             容差区内偏好权重；默认 1.0。


# 六、关节跟踪与扭矩（Coordinator 的 SQP 模式）
#
# --joint-stiffness J1 J2 J3 J4 J5 J6 J7
#   关节阻抗刚度；默认 80 80 80 60 25 15 10。
#
# --joint-damping J1 J2 J3 J4 J5 J6 J7
#   关节阻抗阻尼；默认 17.8885 17.8885 17.8885 15.4919 10 7.746 6.3246。
#
# --pid-proportional-gain FLOAT                    默认 0.18。
# --pid-integral-gain-s FLOAT                      默认 0.30。
# --pid-velocity-gain-s FLOAT                      默认 0.04。
# --pid-maximum-correction-rad RAD                 单关节修正上限；默认 0.05236 rad（3 deg）。
# --pid-integration-error-limit-rad RAD            进入积分的误差上限；默认 0.06981 rad（4 deg）。
# --pid-integral-time-constant-s SEC               运动时积分泄漏时间常数；默认 1.0 s。
# --pid-stationary-integral-time-constant-s SEC    静止时积分泄漏时间常数；默认 0.25 s。
# --pid-stationary-velocity-threshold-rad-s RAD_S  静止判断阈值；默认 0.02 rad/s。

#
# --max-torque-rate NM_S
#   扭矩变化率上限；默认 1000，按固定 1 ms 限幅并封顶到 libfranka 上限。
